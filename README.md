# DivineTube Ultimate

Mobile-first YouTube-style web app upgraded with:
- Dedicated vertical Shorts feed with autoplay on scroll
- Shorts like/share/mute controls
- Cleaner content-first mobile UI
- Bottom navigation and responsive desktop layout
- In-page mini-player behavior on watch pages
- Settings page
- PWA manifest
- Supabase-ready configuration retained from the previous build

Supabase URL/key remain in js/config.js. Use the publishable browser key only and keep RLS enabled.
